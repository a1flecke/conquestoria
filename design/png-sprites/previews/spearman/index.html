Spearman: image-generated strip prototype

What a soldier drawn from ChatGPT-generated animation strips would look like on a hex map, with every movement the game asks a unit for.

Prototype only. Not wired into the game. The game's PNG player does not accept these strips yet; this page draws the sheet the prototype tool built (scripts/sprite-puppet/strips.py).

On the map

Civ colour
In the game a unit crosses one hex in 220 ms and a whole move is capped at 800 ms.

Every movement, looping

The six states the game sends a unit (idle, walk, attack, hurt, death, work). Each loops here so you can judge the motion.

Damage tiers

The same four health bands the game uses (76-100, 51-75, 26-50, 0-25).

Size check

The soldier at the heights a unit really draws on screen. Check the face, shield and spear still read.

What is real and what is not

  • All six game states have real drawn frames here. Today the game only draws idle, walk and attack for a PNG unit; hurt, death and work reuse the idle frame with a colour filter.
  • Damage tiers exist for the standing pose only. Walking, attacking and the others still show the healthy soldier at low health. Covering every movement at every tier would take four times the art.
  • The soldier only faces right, as with every unit today.
  • The civ colour is applied at run time from a mask of the red cloth, the same way the game tints PNG units.
