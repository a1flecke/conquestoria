Unit strip preview

What a unit drawn from ChatGPT-generated strips (plus loops built in code) would look like on a hex map, with every movement the game asks a unit for.

Prototype only. Not wired into the game. The game's PNG player does not accept these strips yet; this page draws the sheet the prototype tool built (scripts/sprite-puppet/strips.py).

On the map

Civ colour
In the game a unit crosses one hex in 220 ms and a whole move is capped at 800 ms.

Every movement, looping

The states the game sends a unit (idle, walk, attack, hurt, death, work). Each loops here so you can judge the motion; a state this unit has no art for is left out.

Damage tiers

The same four health bands the game uses (76-100, 51-75, 26-50, 0-25).

Walking at each tier

The walk is built in code from each damage drawing, so a wounded unit moves wounded. A tier whose drawing could not be cut walks like the previous tier (the build prints a warning).

Size check

The unit at the heights it really draws on screen. Check the face, shield and weapon still read.

What is real and what is not

  • Today the game only draws idle, walk and attack for a PNG unit; hurt, death and work reuse the idle frame with a colour filter. Every state this unit has art for is shown here.
  • Damage tiers always exist for the standing pose. Another movement shows the wounded unit only when it is built from each damage drawing (the walk is); the rest show the healthy unit and the page says so.
  • The unit only faces right, as with every unit today.
  • The civ colour is applied at run time from a mask of the red cloth, the same way the game tints PNG units.
