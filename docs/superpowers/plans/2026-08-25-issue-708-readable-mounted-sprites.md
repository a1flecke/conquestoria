# Issue 708 Readable Mounted Sprites Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Beast Handler, War Elephant, and Cuirassier with readable grounded-fantasy native sprites whose walk and attack animations are driven by believable anatomy.

**Architecture:** `design/conquestoria-sprites/lib/units-v2.jsx` remains the sole hand-authored source for these native v2 sprites; the serializer regenerates their three tracked `*.svg.ts` modules and the standalone preview payload. CSS owns all time-based motion through semantic anatomy hooks, so each state remains legible when paused or under reduced motion. The DOM-overlay path, unit catalog, game rules, save format, AI, SFX, and hot-seat state are intentionally unchanged.

**Tech Stack:** existing JSX runtime and server serializer, SVG, CSS keyframes, Vitest, Playwright screenshot capture, Markdown.

### Visual-review truth table

| Reviewer sees | Reviewer action | Immediate result |
| --- | --- | --- |
| Three generated native sprites in the preview | Select a faction | All three rerender from that faction's serialized payload, with the same anatomy and faction-dependent cloth/harness/saddle/standard surfaces. |
| Idle sprite cards | Select walk, attack, hurt, or death | Both wrapper and inner SVG receive that `data-state`; no mock or proxy asset is substituted. |
| Any state | Enable reduced motion | CSS animation is suppressed while anatomy, selection/health compatibility, faction surfaces, and the static state remain visible. |

### Misleading-review risks

- The preview must not call a silhouette guide, hand-drawn board, or stale generated output “actual renderer output.” It must read only the embedded data regenerated by `serialize-sprites.mjs`.
- A faction dropdown cannot imply six separate illustrations. It demonstrates one stable silhouette with palette-derived identity surfaces.
- No still frame can prove timing by itself. The preview must retain live state controls; the Markdown state sheets are anatomy/readability evidence, not a claim that static images prove motion.
- “Reduced motion” means animations are disabled, not that the sprite or player-visible selection/health/fog information disappears.

### Review interaction replay checklist

- Select each of the six factions, then return to Imperials; every card remains present and the current state remains selected.
- Cycle idle → walk → attack → hurt → death → idle; both wrapper and SVG state attributes update every time.
- Enable reduced motion in both idle and attack, then disable it; the state remains unchanged while only motion policy changes.
- Open the same page directly with `file://` and through Vite; both show all three cards without imports or network requests.
