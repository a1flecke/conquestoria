# NORAD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Era 11 NORAD legendary wonder using the existing typed military-history, tactical-effect, AA-coverage, and air-interception systems.

**Architecture:** NORAD is declaration data, not an AA or strategic-deterrence subsystem. Its `specific-buildings` Radar quest and `successful-interceptions` history quest are evaluated by existing generic quest paths; `aa-radius-extension` and `first-owner-turn-interception-modifier` are resolved by the existing canonical AA and interception helpers. The PR adds only the definition, catalog/Codex fallback data, and tests that prove the existing consumers honor NORAD's live definition.

**Tech Stack:** TypeScript, Vitest, existing legendary-wonder systems, Canvas landmark fallback, DOM wonder panel.

---

## Audited current-main facts

- `providersForOwner()` in `src/systems/air-defense-system.ts` already makes a SAM provider conditional on completed required buildings and delegates only SAM radius to `getTacticalSamRadius()`.
- `isWithinTacticalSamCoverage()` recognizes only a completed-wonder-expanded SAM provider; Mobile AA, city AA, Missile Cruiser AA, and ordinary radius-two SAM coverage cannot make a fighter eligible.
- `resolveAirStrike()` already claims the first eligible owner-turn interception before combat and passes the returned multiplier through `buildCombatContextForDefender()`.
- `successful-interception` is already emitted at the canonical air-combat mutation source. Radar Stations use the generic `specific-buildings` / `distinct-cities` evaluator; they do not need a second history stream.
- Tactical claim state is already serialized and normalized. NORAD adds no persisted property and must not change the save schema.
- The legacy plan's optional search alias is stale: current main has no legendary-wonder search/index surface. Do not add unconsumed alias data.

## Player Truth Table

| Before | Player action | Immediate visible result |
|---|---|---|
| Eligible city has NORAD requirements but quests are incomplete | Open the Legendary Wonders panel | NORAD shows its full acronym on first explanatory use, exact Radar/interception progress, and the locked reward scope. |
| Owner completes NORAD and has a Radar + SAM city | Close and reopen the panel or inspect the coverage surface | The reward text states SAM radius 3 and the first eligible owner-turn interception +10%; only the owner sees own provider detail. |
| A first eligible interception resolves | The canonical air-strike resolver resolves it | Combat facts show the +10% interception modifier; a later interception that owner turn has no NORAD modifier. |

## Misleading UI Risks

- “Radius 3” must never imply that Mobile AA, city AA, Missile Cruiser AA, an unpowered SAM, or another civilization's SAM changed radius.
- “First interception” must never imply a persistent +10% bonus; the panel/Codex wording says first eligible owner-turn interception.
- NORAD must spell out North American Aerospace Defense Command in explanatory copy; no visual, sound, or color-only disclosure may carry a mechanical fact.

- Complete/reload a state with NORAD, reopen the wonder panel, and verify the same exact reward text.
- Resolve two eligible intercepts in one owner turn and inspect the first and second combat facts.
- Switch active hot-seat viewer and verify an unseeing viewer cannot obtain another civilization's provider detail or tactical claim state through panel/coverage output.
